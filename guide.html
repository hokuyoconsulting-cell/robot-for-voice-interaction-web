ボイスロボットの作り方

iPhoneアプリ「ボイスロボット」で動かす、手のひらサイズのロボットの作り方です。はんだ付けは要りません。

1. 用意する部品

部品数
M5Stack ATOM Echo（本体。スピーカー・マイク付きの小さなマイコン）1
ATOM TailBAT（M5Stack製の電池・200mAh）1
赤色LED 3mm（目）2
抵抗 150Ω2
ミニブレッドボード 170穴（はんだ不要）1
ジャンパーワイヤー（オス－オス。本体とブレッドボードの間）3
ジャンパーワイヤー（オス－メス。ブレッドボードとLEDの間）4
外側のケース（例：直径約8cmの球体の缶）1

ほかに、書き込みに使うパソコン（Windows・Mac）、USBケーブル（USB Type-C）、iPhoneが必要です。

2. 配線

ブレッドボードのしくみ：縦に並んだ5つの穴（a〜e）は、中でつながっています。横の穴どうしはつながっていません。真ん中の溝の上と下もつながっていません。今回は上半分（a〜e）だけを使います。

図の黒い四角が、挿す穴です。同じ列（縦の並び）なら、a〜eのどの穴に挿しても同じです。

つなぐもの挿す穴
本体 G21 →（オス－オス）3列 a
本体 G（GND）→（オス－オス）8列 a
本体 G25 →（オス－オス）13列 a
抵抗 150Ω（左目用）3列 c と 6列 c
抵抗 150Ω（右目用）10列 c と 13列 c
左目LEDの長い足（＋）←（オス－メス）6列 e
左目LEDの短い足（－）←（オス－メス）8列 d
右目LEDの長い足（＋）←（オス－メス）10列 e
右目LEDの短い足（－）←（オス－メス）8列 e

LEDは、足の長い方が＋です。逆に挿すと光りません。オス－メスのワイヤーは、メスの側をLEDの足に差し込み、オスの側をブレッドボードに挿します。

3. 本体のプログラム

本体に書き込むプログラムは、下のフォームからお申し込みいただくと、メールでお届けします。作ってみた感想をお聞きしてもよい方は、フォームでお知らせください。

プログラムの「ここに〜」の2か所（テザリングの名前とパスワード）の書きかえ以外の改造と、ほかの人への配布は認めていません。

プログラムを申し込む

4. 本体に書き込む

  1. Arduino IDE（本体にプログラムを書き込むための無料のソフト）を、Arduinoの公式ページからダウンロードして、パソコンに入れます。
  2. Arduino IDE を開き、上のメニューの「ファイル」→「基本設定」を開きます。「追加のボードマネージャのURL」の欄に、次の文字をそのまま貼り付けて「OK」を押します。
    https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json
  3. 左の列の「ボードマネージャ」（基板の絵）で「M5Stack」と探して「インストール」を押します。
  4. 同じく左の列の「ライブラリマネージャ」（本が並んだ絵）で「M5Unified」と探して「インストール」を押します。
  5. メールのリンクから colon01.ino をダウンロードします。
  6. ダウンロードした colon01.ino は、ふつう「ダウンロード」フォルダに入ります。これを、次の場所に移動します。
    • 「ドキュメント」フォルダの中の「Arduino」フォルダを開きます（Windowsなら C:\Users\（お名前）\Documents\Arduino、Macなら「書類」→「Arduino」）。「Arduino」フォルダがなければ、新しく作ります。
    • その中に、新しいフォルダを作って、名前を「colon01」にします。
    • 「ダウンロード」フォルダの colon01.ino を、この「colon01」フォルダの中に移動します。2回以上ダウンロードすると「colon01 (2).ino」のように名前が変わることがあります。そのときは、名前を「colon01.ino」に変えてから移動します。
    • フォルダの名前とファイルの名前は、同じ「colon01」でないと、Arduino IDE で開けません。
  7. colon01 フォルダの中の colon01.ino をダブルクリックして、Arduino IDE で開きます。
  8. プログラムの上の方にある「ここにテザリングの名前」「ここにテザリングのパスワード」の2か所を、ご自分のiPhoneのものに書きかえます（" と " の間だけ）。
    • テザリングの名前：iPhoneの「設定」→「一般」→「情報」→「名前」に出ている名前です（例：○○のiPhone）。
    • テザリングのパスワード：iPhoneの「設定」→「インターネット共有」→「Wi-Fiのパスワード」に出ている文字です。
  9. 本体をUSBケーブルでパソコンにつなぎます。
  10. Arduino IDE の画面の上にある「ボードを選択」の欄を押し、「M5Atom」を選びます。見つからないときは、上のメニューの「ツール」→「ボード」→「M5Stack」→「M5Atom」で選びます。
  11. 上のメニューの「ツール」→「ポート」で、本体のポートを選びます（Windowsは「COM」と数字、Macは「/dev/cu.usbserial」で始まる名前）。
  12. 画面の左上にある「→」（右向きの矢印）のボタンが書き込みボタンです。押すと書き込みが始まり、下に「書き込み完了」と出たら終わりです。
  13. うまくいかないときは、「ツール」→「Upload Speed」を「115200」にして、もう一度「→」を押します。

5. 動かす

  1. iPhoneの「設定」→「インターネット共有」を開き、「ほかの人の接続を許可」と「互換性を優先」をオンにします。この画面を開いたまま、本体の電源を入れます（TailBATのボタンを1回押す。切るときは素早く2回押す）。
  2. 本体が「ピッ」と鳴ったら、iPhoneでアプリ「ボイスロボット」を開きます。
  3. OpenAIのAPIキー（AIを使うための合い言葉）を用意します。
    • ChatGPTのアプリや有料プラン（ChatGPT Plus など）とは別のものです。ChatGPTにお金を払っていても、APIのお金は別に入れる必要があります。
    • OpenAIの開発者向けページ（platform.openai.com）でアカウントを作り、支払い方法を登録して、使う分のお金を先に入れます（クレジット）。
    • 同じページの「API keys」で「Create new secret key」を押すと、「sk-」で始まる長い文字が出ます。これがAPIキーです。一度しか表示されないので、すぐにコピーします。
  4. アプリの右上の歯車 →「OpenAIのAPIキー」の欄に貼り付けて、「保存して確かめる」を押します。
  5. 本体に話しかけると、「ナニ？ナニ？」と答えて聞き取り、返事をします。

アプリを開いている間だけ動きます。画面がつきっぱなしになるので、iPhoneの電池が早く減ります。OpenAIの利用料は、APIキーを登録したご本人に請求されます。
